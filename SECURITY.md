# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of SplitFlow seriously. If you discover a security vulnerability, please do NOT file a public issue.

Instead, please email the project maintainer directly at **security@splitflow.app** or open a private security advisory on GitHub.

We will acknowledge receipt within 48 hours and work with you on a timely resolution.
